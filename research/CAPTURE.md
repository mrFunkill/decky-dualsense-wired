# Захват Bluetooth-трафика DSX → DualSense

Цель: увидеть, какие HID-отчёты DSX отправляет контроллеру по Bluetooth
(в первую очередь функции DLC «Unlock Bluetooth Audio and Haptic Feedback»).
Изучаем только трафик между ПК и своим контроллером. Код DSX не разбираем.

## Установка (один раз, нужны права администратора)

```powershell
winget install WiresharkFoundation.Wireshark
winget install desowin.USBPcap
```

После установки USBPcap перезагрузите ПК.

## Как пишется трафик

Bluetooth-адаптер TP-Link (USB `2357:0604`) подключён по USB, поэтому USBPcap видит
весь HCI-трафик: L2CAP → HID-отчёты контроллера.

Запись делает скрипт [capture.ps1](capture.ps1). Он пишет **только** адаптер
(хаб `USBPcap1`, устройство 2), без клавиатуры, мыши и звуковых устройств.
Запускайте скрипт из обычного (не административного) PowerShell: USBPcap сам
запросит права через окно UAC и будет писать в фоне, пока запись не остановят.

1. **Выключите контроллер** (удерживайте PS ~10 с) и закройте DSX, если сценарий этого требует.
2. Запустите запись и подтвердите запрос UAC:
   ```powershell
   cd D:\deckyloader\research
   ./capture.ps1 01-baseline
   ```
3. Включите контроллер кнопкой PS. Wireshark должен увидеть установку
   L2CAP-каналов HID (PSM 0x11/0x13), иначе он не распознает отчёты.
4. Выполните сценарий и остановите запись (снова подтвердите запрос UAC):
   ```powershell
   ./capture.ps1 -Stop
   ```
   Файл появится в `D:\deckyloader\research\captures\<имя>.pcap`.
   Время действий отмечайте в `captures\notes.txt`.

## Сценарии

| Файл | Что делать |
|---|---|
| `01-baseline.pcap` | DSX закрыт. Включить контроллер, 10 с покоя, нажать несколько кнопок. |
| `02-dsx-start.pcap` | Запустить DSX при подключённом контроллере, подождать 10 с. |
| `03-lightbar-triggers.pcap` | В DSX сменить цвет подсветки, затем включить 2–3 разных режима адаптивных триггеров. |
| `04-rumble.pcap` | Обычная вибрация (тест в DSX или игра без HD-тактильных эффектов). |
| `05-bt-haptics.pcap` | Включить функцию DLC Bluetooth Haptics и запустить тест тактильных эффектов в DSX или игру с ними, 10–15 с. |
| `06-bt-speaker.pcap` | Включить звук на динамик контроллера через DLC, проиграть звук 10 с. |
| `07-bt-headset.pcap` | Если есть наушники: подключить в разъём контроллера, проиграть звук 10 с. |
| `08-bt-mic.pcap` | Если DSX это поддерживает: включить микрофон контроллера, говорить 10 с. |

Короткие записи (10–20 с) лучше длинных: в них проще найти нужные пакеты.

## Что будем искать

- Номера и размеры выходных отчётов (известны 0x31, а также 0x32–0x39 разной длины).
- Структуру заголовков, счётчики последовательности и CRC32.
- Частоту пакетов и формат аудиоданных (PCM, Opus, SBC и т.п.) для haptics и динамика.
- Feature-отчёты (`SET_REPORT`), которыми DSX включает режимы.
